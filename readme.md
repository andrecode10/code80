# CODE80 — онлайн-площадка для продажи и покупки брендовой одежды

## Что это такое

CODE80 — это маркетплейс, где можно быстро и безопасно продать или купить брендовую одежду.  
Продавец загружает фото — ИИ подсказывает бренд, размер и цену.  
Покупатель примеряет вещь виртуально на свою фигуру и получает сертификат подлинности.

## Главные возможности

### Для продавца
- Выставить вещь за 5 минут (ИИ заполняет бренд, размер, категорию)
- Защита от мошенников (паспорт сделки)
- Автоматическая доставка через СДЭК / Boxberry
- Низкая комиссия — от 5% до 15% (зависит от цены вещи)

### Для покупателя
- Виртуальная примерка на модели под твой рост и вес
- Фильтр по бренду, размеру, состоянию (New / Like new / Good)
- Оплата частями (Яндекс.Сплит, Долями)
- Подтверждение подлинности (эксперт или ИИ)

### Логистика
- Расчёт доставки в корзине
- Страховка отправления
- Возврат, если вещь не подошла (по согласованию)

### Для бизнеса
- API для масс-загрузки (PRO-версия)
- Интеграция с кассами и CRM (Amo, RetailCRM)
- Рекламные пиксели, Метрика, GA4
