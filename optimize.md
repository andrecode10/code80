# Как ускорить и улучшить CODE80

## Зачем это нужно?
- Чем быстрее открывается карточка вещи — тем выше покупка.
- 75% заходят с телефона — сайт должен летать на Android и iOS.
- Поисковики любят быстрые сайты → больше трафика бесплатно.

## Что будем ускорять?

| Что именно | Как упростим |
|------------|---------------|
| Фото вещей (часто 5–10 шт) | Сжимаем в WebP, отдаём через CDN, грузим лениво (lazy loading) |
| Поиск + фильтры (бренд, размер, цена) | Используем кэш Redis, не ходим в базу при каждом клике |
| Загрузка страницы каталога | Отдаём первый экран мгновенно, остальное — подгрузка (infinite scroll) |
| Карточка товара | Мета-теги под SEO, микроразметка Schema.org (для Google Shopping) |
| Виртуальная примерка | Нейросеть на WebGL прямо в браузере (без загрузки фото на сервер) |
| Счётчики (Pixel, GA4, Metrica) | Загружаем асинхронно, без блокировки отрисовки |
| Чат-бот для продавцов | Вебхуки вместо постоянных запросов к API |

## Как будем делать?

1. Проверим скорость через Lighthouse, Pagespeed, WebPageTest.
2. Внедрим Service Worker — сайт открывается даже при плохом интернете.
3. Настроим HTTP/2 и Brotli (современное сжатие).
4. Картинки для примерок храним 24 часа и удаляем (по закону о биометрии).
5. Виртуальную прокрутку для ленты рекомендаций («похожие вещи»).
6. Кэшируем результаты поиска на 5 минут (для популярных запросов).
7. Результаты примерки (как сидит вещь) храним локально в браузере 1 час — повторно не считаем.
