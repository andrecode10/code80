# Оценка проекта CODE80

## 1. По каким признакам оцениваем

| Что проверяем | Что это значит | Как измерить |
|---------------|----------------|---------------|
| Конверсия в листинг | Сколько продавцов дошли до публикации товара | % заполнивших все поля (бренд, размер, фото) |
| Качество контента | Насколько четко видно бренд, состояние, дефекты | Оценка модерации, время на загрузку |
| Быстродействие | Как быстро грузятся карточки с фото и поиск | Lighthouse (мобильный) > 70 |
| Безопасность | Защита от подделок, защита данных паспорта | Проверка брендов, шифрование, паспорт сделки |
| Простота для продавца | Сколько времени уходит на выставление вещи | От входа до публикации (цель — 5 минут) |
| Интеграция с доставкой | Автоматический трекинг, возвраты, страховка | API с Boxberry, СДЭК, Почта, DPD |
| Масштабирование | Можно ли загрузить 10 000 вещей без тормозов | Время индексации карточки |
| Комиссия | Сколько берем за сделку | Окупаемость для продавца и платформы |

## 2. Сравнение с конкурентами

| Конкурент | Сильные стороны | Слабые стороны | Чем CODE80 лучше |
|-----------|----------------|----------------|------------------|
| Avito | Гигантский трафик | Нет защиты от подделок, плохой поиск по брендам | Модерация вещей + ИИ-проверка бренда |
| Vinted | Простота, низкая комиссия | Визуал слабый, много дешевого сегмента | Фокус на бренды + качественные фото (как lookbook) |
| The RealReal | Полная аутентификация | Комиссия до 50%, долгая выкладка | Продавец сам фоткает, мы ускоряем через ИИ |
| Grailed | Сильное комьюнити (стритвир) | Сложный вход, только niche | Понятный онбординг + поддержка российских брендов |
| Мешок / Ярмарка | Лояльная аудитория | Устаревший интерфейс, нет примерки | Виртуальная примерка на нейросети + фото похожих вещей |

**Вывод:** CODE80 — первая платформа в РФ, где можно продать брендовую вещь за 5 минут, с автоматической проверкой подлинности и виртуальной примеркой на модели под ваш рост/вес.
